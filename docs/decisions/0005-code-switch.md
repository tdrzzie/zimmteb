# 0005 — Code-switch tracks are distinct from ISO languages

Status: accepted.

Use `eng`, `sna`, `nde` for languages; `eng-sna-codeswitch` and `eng-nde-codeswitch`
are local track identifiers. Record partners, direction, frequency, approximate
ratio, origin and review status. Translate local tracks to their constituent
ISO-script tags only at the MTEB metadata boundary.

Reports preserve each track. No generic multilingual average replaces them.
Fixture switching is artificial and unreviewed; naturalness must be established by
speakers before a research release. Do not confuse Northern and Southern Ndebele.
