# 0008 — Synthetic fixtures test infrastructure only

Status: accepted.

Ship a deterministic, tiny, original synthetic fixture with generator metadata and
CC0 dedication. No speaker approval or translation accuracy is claimed. Reports
carry a visible fixture warning. Mock-model scores are never benchmark baselines.

This enables credential-free CI and CPU smoke tests. It cannot establish retrieval
quality for Zimbabweans. A reviewed release needs broader queries, multiple relevance
judgments, natural switching and source-level split isolation.
