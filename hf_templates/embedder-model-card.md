# zim-embed-small — untrained model-card template

**No checkpoint exists yet. Do not publish as a trained model card.**

| Field | Required release evidence |
|---|---|
| Description/use | Compact Zimbabwe-adapted retriever; measured scope only |
| Base | Exact model ID/revision and inherited license |
| Languages | Actual coverage, weak and missing tracks |
| Datasets | IDs/versions/checksums/licenses, synthetic proportions, review |
| Method | Trainer, loss, negatives, distillation and ablations |
| Training | Seed, optimizer, learning rate, batch/accumulation, precision, length |
| Hardware | GPU/CPU, VRAM/RAM, runtime, versions and checkpoints |
| Evaluation | Held-out run IDs, native MTEB results, slices, uncertainty |
| Efficiency | Parameters, disk size, throughput and latency protocol |
| Bias/limitations | Dialects, orthography, switching, domains, judgments |
| Environmental notes | Measured energy/emissions or explicitly unknown |
| Citation | Actual software/research references; no invented DOI |
| License | Verified base/derived-weight and training-data compatibility |

Embedding scores do not establish fluency, fairness or high-stakes fitness. Use the
same benchmark infrastructure as third-party models.
